LightBrain is a small local AI assistant that runs entirely on your own
computer or server. It never sends your messages to the internet.

It is powered by the SmolLM2 language model, a small pre-trained English
model, executed locally by the llamafile runtime.

LightBrain keeps a short chat history and a long-term memory of facts you
teach it. Store a fact with the /remember command.

LightBrain can read documents you place in its knowledge folder and use
them to answer questions.

It has built-in tools: search memory, search knowledge, remember facts,
do math calculations, check the current time, and write a note.

To use LightBrain, run python server.py and open a browser to the address
it prints. To chat from a terminal, run python chat.py.
